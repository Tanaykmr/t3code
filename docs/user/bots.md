# Bots

A bot is a named agent with its own persona and a private chat. Give it a name, a title and a
persona that says how it works and talks, and it answers as that bot in every turn. Bots can talk
to each other, share rooms with you, start coding work, remember what you ask them to, and run
routines.

## Create a bot

Choose **+** next to **Bots** in the sidebar, or **New bot** in the Bots tab on mobile. If you can
create bots on multiple environments, choose where the bot should live. Pick a home project and an
agent. Bots run on Codex or Claude. The bot's chat opens right away. Its overview
(the details panel on desktop, **Overview** in the chat header on iPhone) shows the profile, where
you can edit it or archive the bot. Restoring an archived bot brings back the same chat.

The dot beside a bot means a reply you have not read yet; reading it on one device clears it on the
others.

## Talk to other bots

- In a bot's chat, type **@** and pick another bot. Only picked bots receive the message; a name you
  type without picking it is plain text. The bot whose chat you are in answers only if you pick it
  too, or pick nobody.
- A bot can message another bot itself, and the answer comes back to it once.
- A **room** is a shared chat with several bots. Pick bots with **@** to choose exactly who answers;
  a message without picks goes to the room's default responder. If that bot is archived, the first
  active member answers. Open a delivery to inspect the bot's work. Send follow-ups in the room.
  Removing a bot from a room stops any of its replies that have not started yet.

Bots cannot grant each other access or approve anything for you.

## Coding work

A bot starts coding sessions the same way any agent delegates work, and reports back in its chat.
By default it works in its home project. To let it work in other projects, edit the bot and pick
them under **Work targets**; each session there gets its own worktree.

## Memory, skills and routines

- Ask a bot to remember a preference and it saves it; you can also add or forget memories in the
  overview. Memory stays in the bot's private chat and is not shared into rooms.
- Skills are instructions the bot follows when a request matches. Add, switch off or delete them in
  the overview; a change applies from the next message.
- Ask a bot to schedule something, such as a weekday reminder, and it becomes a routine bound to its
  chat. Routines show in the overview, where you can pause, edit or run them now.
